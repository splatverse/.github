# splatverse

Open-source Gaussian splatting: turn the real world into 3D scenes you can open in a browser.

| Project | What it is |
|---|---|
| [splat-studio](https://github.com/splatverse/splat-studio) | Video to interactive 3D Gaussian splats: web app, GPU reconstruction worker, iOS capture app and a WebGL viewer. **[Try the live viewer](https://splatverse.github.io/splat-studio/)** |
| [vertex-3d-studio](https://github.com/splatverse/vertex-3d-studio) | Describe an object in plain language and watch it get built in space, out of dots |
| [GaussianSplats3D](https://github.com/splatverse/GaussianSplats3D) | Our fork of the Three.js Gaussian splatting renderer, for contributions upstream |

Everything here is MIT licensed. Looking for games? See [webgl-games](https://github.com/webgl-games).
